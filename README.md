# Dostaffkin

Веб-приложение для доставки товаров с расчётом стоимости, оформлением заказов и отслеживанием статуса доставки.

## Функционал

- **Главная страница** — информация о сервисе и навигация
- **Оформление доставки** — расчёт стоимости, выбор размера посылки (XS–XL) и скорости доставки, интеграция Яндекс.Карт для выбора маршрута
- **Отслеживание** — поиск статуса доставки по номеру заказа
- **Уведомления** — всплывающие алерты при ошибках и успехе операций

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm start
```

По умолчанию приложение откроется на `http://localhost:4200/dostaffkin/`

## Основные команды

| Команда | Описание |
|---------|---------|
| `npm start` | Запуск development сервера |
| `npm run build` | Production сборка в `docs/` |
| `npm run watch` | Сборка в режиме watch |
| `npm test` | Запуск тестов |

## API

Приложение взаимодействует с публичным API `https://testologia.ru/delivery/`:

| Метод | Эндпоинт | Описание |
|-------|----------|---------|
| POST | `/create` | Создание заказа доставки |
| GET | `/info` | Получение статуса доставки по ID |

## Структура проекта

```
src/app/
├── pages/
│   ├── home/      — главная страница
│   ├── order/     — оформление заказа с картой
│   └── track/     — отслеживание доставки
├── services/
│   └── delivery-api.ts    — HTTP клиент
├── header/        — компонент навигации
├── app.routes.ts  — маршруты
└── app.config.ts  — конфигурация
```

## Размеры посылок

- **XS** — 17×12×9 см, до 0.5 кг
- **S** — 23×19×10 см, до 2 кг
- **M** — 33×25×15 см, до 5 кг
- **L** — 31×25×38 см, до 12 кг
- **XL** — 60×35×30 см, до 18 кг
